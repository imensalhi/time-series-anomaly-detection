# time-series-anomaly-detection

Projet de détection d'anomalies dans les séries temporelles.

## 📁 Contenu du dossier `data/`

Le dossier [`data/`](./data/README.md) est le point d'entrée pour toutes les données du projet.  
Il est organisé comme suit :

| Sous-dossier      | Contenu                                                        |
|-------------------|----------------------------------------------------------------|
| `data/raw/`       | Données brutes originales (ne pas modifier)                    |
| `data/processed/` | Données nettoyées et prétraitées                               |
| `data/train/`     | Jeux de données d'entraînement des modèles                     |
| `data/test/`      | Jeux de données de test et d'évaluation des modèles            |

Pour une description complète du format des données, des sources et des conventions, consultez le fichier **[data/README.md](./data/README.md)**.
